    생성형 AI 기본 개념¶

    생성형 AI 와 다른 AI 의 차이¶

    유형 하는 일 예시
    전통적 machine learning 데이터에서 패턴을 학습해 예측/분류 이탈 고객 예측, 스팸 분류
    Computer vision 이미지/영상을 인식/분석 제품 결함 탐지, OCR
    자연어 처리 (NLP) 언어를 이해/분석 감정 분석, 개체 추출
    생성형 AI (Generative AI) 새로운 콘텐츠를 생성 문서 초안, 이미지, 코드, 요약

    핵심 구분

    생성형 AI 는 기존 데이터를 분류/예측하는 것을 넘어, 학습한 패턴을 바탕으로 새로운 결과물을 만들어낸다는 점이 다릅니다. 대부분 large language model (LLM) 또는 멀티모달 모델을 기반으로 합니다.

    AI 모델의 종류¶

    Pretrained vs Fine-tuned¶

    구분 설명 언제 쓰나
    Pretrained model 대규모 공개 데이터로 이미 학습된 범용 모델 (예: GPT 계열) 일반적인 작업, 빠른 시작
    Fine-tuned model pretrained 모델을 자사 도메인 데이터로 추가 학습 특정 업무/말투/전문 영역이 필요할 때

    선택 기준

    대부분의 비즈니스 요구는 pretrained + grounding/RAG 로 충분합니다. Fine-tuning 은 데이터가 충분하고, 반복되는 전문 작업에서 일관된 출력이 필요할 때 고려합니다. (비용/유지관리 부담이 큼)

    Reasoning vs Non-reasoning 모델¶

    • Non-reasoning 모델: 빠르게 텍스트를 생성. 요약, 초안 작성, 간단한 응답에 적합.
    • Reasoning 모델: 다단계 추론/문제 해결에 강함. 복잡한 분석, 계획 수립에 적합하나 비용/지연이 큼.

    비용 드라이버 (Cost drivers)¶

    • Token: 생성형 AI 의 과금 단위. 입력(prompt) + 출력(completion) 토큰 수에 비례해 비용이 발생.
      • 긴 prompt, 긴 응답, 대량 호출은 모두 비용을 키움.
    • 모델 등급: 더 크고 강력한 모델일수록 토큰당 단가가 높음.
    • ROI 관점: 절감되는 인건비/시간 대비 토큰 비용을 비교. 자동화되는 반복 작업이 많을수록 ROI 가 높음.

    ROI 사고 방식

    "월 1만 건의 고객 문의 1차 응답을 자동화 -> 상담원 시간 절약" 처럼, 규모(scale) 가 클수록 토큰 비용을 상쇄하고 가치가 커집니다.

    도전 과제 (Challenges)¶

    위험 설명 완화 방법
    Fabrication (환각, hallucination) 사실이 아닌 내용을 그럴듯하게 생성 grounding, RAG, 출처 표기, 사람 검토
    Reliability (신뢰성) 같은 질문에 다른/일관되지 않은 답 명확한 prompt, 온도 조절, 검증 절차
    Bias (편향) 학습 데이터의 편향이 결과에 반영 대표성 있는 데이터, responsible AI 검토

    비즈니스 가치가 생기는 시점¶

    생성형 AI 는 다음 조건에서 가치가 커집니다.

    • Automation (자동화): 반복적이고 규칙적인 콘텐츠/응답 작업을 대체.
    • Scalability (확장성): 사람이 감당하기 어려운 대량 작업을 즉시 확장.
    • Augmentation (증강): 직원의 초안/분석/검색을 보조해 생산성 향상.

    가치가 낮은 경우

    정답이 명확하고 규칙 기반으로 충분한 작업, 극도의 정확성이 요구되어 사람 검토 비용이 오히려 더 큰 작업에서는 생성형 AI 의 가치가 제한적입니다.

    요약¶

    • 생성형 AI = 새 콘텐츠 생성, 전통 AI = 예측/분류.
    • Pretrained 로 시작하고, 필요할 때만 fine-tune.
    • 비용은 token 기준, 가치는 scale/automation 에서 나옴.
    • fabrication/bias/reliability 는 항상 관리 대상.
