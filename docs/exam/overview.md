### Domain 1 - 생성형 AI 솔루션의 비즈니스 가치 (35-40%)

- 생성형 AI 의 **기본 개념** 식별
    - 생성형 AI 와 다른 유형 AI 의 차이
    - 비즈니스 요구에 맞는 생성형 AI 솔루션 선택
    - AI 모델의 차이 (fine-tuned vs pretrained)
    - 비용 드라이버 (token, ROI)
    - 도전 과제 (fabrication, reliability, bias)
    - 비즈니스 가치가 생기는 시점 (scalability, automation)
- 생성형 AI 솔루션의 **이점과 기능**
    - Prompt engineering 의 영향과 기법
    - Grounding 요구사항
    - RAG (retrieval-augmented generation)
    - 데이터의 영향 (type, quality, representativeness)
    - Secure AI 의 중요성
    - Machine learning 이 가치를 더하는 시나리오와 lifecycle
    - AI 보안 고려사항 (application/data security, authentication)

### Domain 2 - Microsoft AI 앱/서비스의 이점, 기능, 기회 (35-40%)

- **Microsoft 365 Copilot & Microsoft Copilot**
    - 비즈니스 프로세스/유스케이스를 Copilot 에 매핑
    - Copilot 버전 간 기능 차이
    - Copilot Chat (web/mobile), M365 앱 내 Copilot
    - Microsoft Copilot Studio, Microsoft Graph
    - 통합 AI 솔루션의 이점 (risk mitigation, safety)
    - Researcher / Analyst 사용 시점
    - build / buy / extend 판단, 확장성 프레임워크
- **Foundry Tools**
    - 유스케이스를 Foundry Tools 에 매핑
    - Azure AI Vision, Azure AI Search, Microsoft Foundry
    - 비즈니스 요구에 맞는 AI 모델 선택
    - Foundry 의 이점 (scalability, security)

### Domain 3 - 구현 및 도입 전략 (20-25%)

- **Responsible AI 정책 정렬**
    - Responsible AI 의 중요성, governance 원칙
    - AI council 구성
    - 6대 원칙 준수 (fairness, reliability & safety, privacy & security, inclusiveness, transparency, accountability)
- **조직 전반의 AI 도입 계획**
    - Adoption team, AI champions program
    - 도입 장벽 식별
    - 데이터/보안/프라이버시/비용 영향
    - Copilot 라이선스 유형, Foundry Tools 구독 모델
