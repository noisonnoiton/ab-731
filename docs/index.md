# AB-731: AI Transformation Leader

이 사이트는 **Microsoft Certified: AI Transformation Leader** (시험 코드 **AB-731**) 대비 강의 자료입니다.

!!! info "대상자 (Audience)"
    코드를 작성하지 않는 **비즈니스 의사결정자**를 위한 자격증입니다. AI 도입 기회를 발견하고, 적절한 도구를 선택하며, responsible AI 를 실천하고, AI 투자를 비즈니스 목표와 정렬하는 역량을 다룹니다. Microsoft 365 Copilot, Microsoft Foundry, 일반적인 AI 기능에 대한 이해가 필요합니다.

## 이 과정에서 다루는 것

| 도메인 | 비중 | 핵심 주제 |
| --- | --- | --- |
| [Domain 1](domain1-business-value/index.md) | 35-40% | 생성형 AI 기본 개념, prompt engineering, grounding, RAG, machine learning |
| [Domain 2](domain2-ai-apps-services/index.md) | 35-40% | Microsoft 365 Copilot, Copilot Studio, Microsoft Graph, Foundry Tools |
| [Domain 3](domain3-implementation-adoption/index.md) | 20-25% | Responsible AI, governance, 도입 전략, 라이선스 |

## 학습 순서 권장

1. [시험 정보](exam/overview.md) - 시험 형식, 채점, 기술 영역을 먼저 확인
2. **Domain 1** - AI 기본 개념과 비즈니스 가치 (비중 최대)
3. **Domain 2** - Microsoft 제품/서비스 매핑
4. **Domain 3** - 조직 도입과 responsible AI
5. [용어집](glossary.md) - 핵심 용어 복습
